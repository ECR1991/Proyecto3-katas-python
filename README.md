# Proyecto 3 - Katas Python

Este repositorio contiene la resolución del **Proyecto 3 – Katas Python**, cuyo objetivo es afianzar los conocimientos básicos del lenguaje Python mediante la realización de distintos ejercicios prácticos.

Los ejercicios han sido desarrollados siguiendo los enunciados proporcionados por el profesor y utilizando soluciones sencillas, claras y fáciles de entender.

---

## 📌 Objetivo del proyecto

El objetivo principal de este proyecto es demostrar el uso de los fundamentos de Python, poniendo en práctica conceptos básicos de programación y buenas prácticas de desarrollo.

---

## 📂 Estructura del repositorio

El repositorio contiene, al menos, los siguientes archivos:

- **katas.py**  
  Archivo principal que incluye todos los ejercicios resueltos.  
  Cada ejercicio está numerado y encabezado con el enunciado correspondiente.

- **COMENTARIOS.md**  
  Documento donde se explican los pasos seguidos durante el desarrollo del proyecto y los conceptos trabajados.

- **README.md**  
  Archivo descriptivo del proyecto.

---

## 🧠 Contenidos trabajados

Durante el desarrollo del proyecto se han trabajado los siguientes conceptos:

- Tipos de datos básicos
- Listas, tuplas, diccionarios y conjuntos
- Condicionales (`if`, `elif`, `else`)
- Bucles (`for`)
- Funciones
- Funciones lambda
- Uso de `map()`, `filter()` y `reduce()`
- Manejo de excepciones (`try / except`)
- Programación orientada a objetos (clases y métodos)
- Entrada de datos por teclado
- Buenas prácticas y código legible

---

Para ejecutar el proyecto:

1. Abrir el archivo `katas.py` en Visual Studio Code.
2. Asegurarse de tener Python instalado.
3. Ejecutar el archivo utilizando el botón **Run Python File** o desde la terminal con el comando:

   ```bash
